# ប្រព័ន្ធចងក្រង SOP គ្លីនិក — SAY RAS CLINIC

គេហទំព័រស្ថិត (GitHub Pages) + API នៅលើ Google Apps Script + Google Sheet ជាមូលដ្ឋានទិន្នន័យ។
បុគ្គលិកបើកតាម link ធម្មតា **ដោយមិនចាំបាច់មានគណនី**។ អ្នកគ្រប់គ្រងកែបានគ្រប់ផ្នែកដោយលេខសម្ងាត់។

## តើវាដំណើរការយ៉ាងណា

```
កម្មវិធីរុករក  ──GET  ?action=bootstrap──►  Apps Script  ──►  Google Sheet
(GitHub Pages) ──POST {action:…}       ──►   Web App
```

Apps Script មិនអាចដាក់ CORS header ដោយខ្លួនឯង ហើយក៏មិនឆ្លើយតប `OPTIONS` ដែរ។
ដូច្នេះ `api.js` ប្រើតែ **simple request**៖ `GET` ធម្មតា និង `POST` ដោយ**មិនកំណត់ header**
(កម្មវិធីរុករកដាក់ `Content-Type: text/plain` ឱ្យ ដែលមិនបង្កើត preflight)។
បើ `GET` ជាប់ CORS ប្រព័ន្ធប្តូរទៅ **JSONP** ដោយស្វ័យប្រវត្តិ។

## តេស្ត

```bash
node tools/mock-server.mjs          # រត់ backend ពិតក្នុង Node + បម្រើ docs/
PIN=<pin> node tools/test-e2e.mjs   # តេស្តពីដើមដល់ចប់ (៣១ ករណី)
node tools/test-print.mjs           # រាប់ចំនួនទំព័រ A4 (៤ ករណី)
```

`mock-server.mjs` រត់ `Code.gs` និង `Seed.gs` **ពិតប្រាកដ** ក្នុង Node ដោយប្រើសេវាត្រាប់តាម
ហើយបម្រើគេហទំព័រនៅ port ផ្សេង ដូច្នេះការតេស្តឆ្លងកាត់ CORS ពិតដូចនៅលើអ៊ីនធឺណិត។

## សុវត្ថិភាព

- គ្រប់សកម្មភាពអ្នកគ្រប់គ្រងត្រូវផ្ទៀងផ្ទាត់លេខសម្ងាត់នៅខាងម៉ាស៊ីនបម្រើរាល់ដង
- ប្រៀបធៀបលេខសម្ងាត់ជាពេលថេរ (constant-time) + កំណត់ ៨ ដងក្នុង ១០ នាទី
- គ្រប់តម្លៃជម្រើសត្រូវឆ្លងកាត់បញ្ជីអនុញ្ញាតនៅខាងម៉ាស៊ីនបម្រើ
- `LockService` ការពារការសរសេរជាន់គ្នា
- ⚠️ ឯកសារភ្ជាប់ក្នុង Drive ចែករំលែកជា "anyone with the link" — **ហាមភ្ជាប់ព័ត៌មានអ្នកជំងឺ**
